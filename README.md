# Tabletop Voice

Tabletop Voice is an independent browser-based companion for tabletop gaming. It supports local roster import, fast datasheet lookup, voice search, scoring, dice tools and device-to-device roster transfer.

## Data model

The app does not ship with Warhammer 40,000 rules, codex text, datasheets or artwork. Users choose to load compatible roster files and/or supported community-maintained reference data in their own browser.

Imported rosters and app state are stored locally on the user's device. The app does not require an account and LimboTech does not operate a central roster library for the public beta.

See [Privacy & About](./privacy.html) for the current data-handling details and third-party services used by the app.

## Unofficial project

Tabletop Voice is not affiliated with, endorsed by or sponsored by Games Workshop. Warhammer and related names and marks belong to their respective owners. Official publications remain the authoritative source for game rules.
